# Security Policy

## Supported Versions

Only the latest chart release is supported. A fix ships as the next release.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/zimmertr/bluebird-helm/security/advisories/new).
Do not open a public issue for security problems.

Include what you found, where it lives (template, value, or workflow), and how to reproduce it.

What to expect:

- **Acknowledgement** within a few days. This is a one-person project, so response times are best effort.
- **Fix**: a confirmed vulnerability is fixed in the next chart release.
- **Credit** in the advisory, unless you'd rather not.

## Scope

In scope: the chart in `charts/bluebird` and the CI workflows.

Out of scope: the Bluebird app itself (report those at [zimmertr/bluebird](https://github.com/zimmertr/bluebird/security/advisories/new)) and the CloudNativePG subchart, whose issues go to its maintainers.

There is no bounty program. Reports are still appreciated.
